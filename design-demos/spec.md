# Sortie Deck 设计方向探索 · Spec

## 产品是什么
Sortie Deck：AI 原生的办公迭代控制平面。为每个任务（mission）编排一组角色 Agent，
LangGraph 驱动流水线，关键节点人在环（HITL）审批，阶段间以产物契约传递。
核心界面 = 任务视图：顶部导航 + 流水线节点编排（角色节点）+ 阶段清单（含门禁）。

## 目标受众与场景
研发团队日常使用（盯流水线、批 HITL、长时使用、效率优先），兼顾对外演示。
→ 专业、克制、信息密度优先；去掉娱乐化装饰（动漫立绘、六边形霓虹头像、发光描边）。

## 内容（三版共用，真实数据）
- 导航：工作台 · 任务（当前）· 知识库 · 记忆 · 角色工场 · 工具箱 · 小队 · 决策中心 · 管理
- 任务：门户预发健康检查 · standard 航线 · 运行中 · 8 角色
- 流水线：集结(完成)→PRD(完成+门禁)→技术方案(进行中+门禁)→设计→开发并行×4(后端/iOS/Android/Web)→联调测试(门禁)→上线(门禁)
- 阶段表 10 行（intake / product_prd / eng_tech_design / design_ui / eng_backend / eng_ios / eng_android / eng_web / qa_verify / deploy），含角色、依赖、门禁、状态
- HITL 横幅：技术方案评审等待 /approve

## 情感基调
可靠、清晰、安静的专业工具感。状态用颜色语义（完成=品牌绿、进行中=蓝、门禁=珊瑚红点），
不用发光/渐变堆砌。视觉温度：冷静、可信任。

## 品牌约束
- 唯一 accent：logo 握手绿 #3FD68F（浅底下降饱和为 #1F9D61 保证对比度）
- 辅助点：珊瑚红 #F0605A（门禁/阻塞）、蓝 #4A7DFF（进行中）
- 无字体规范：file:// 离线可开，用系统字体栈，不引外部资源

## 输出格式
单文件 HTML，目标视口 1440×900；每个版本内置 明/暗 主题切换（CSS 变量 + 按钮 + ?theme= 参数）。

## 图片判断
工具/数据型界面 → 图片非内容必需，零装饰图（反 slop：不加 stock 配图）。
