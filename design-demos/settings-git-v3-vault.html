KEY CABINET / 钥匙柜

公用钥匙封存，私钥自己配

工作区凭据是封在保险格里的公用钥匙，只能看；个人凭据是你自己配的钥匙，可以改、可以熔断。右侧抽屉里用一个竖排目录切换。

设计取向：把权限差异做成材质差异——封条、蜡印、斜纹代表「不可动」，钥匙齿纹代表「这是我的」。信息结构不变，但这一版最容易被记住，也最适合截图传播。
