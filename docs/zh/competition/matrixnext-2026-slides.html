02 · 方案

把「聊天接力」换成控制面

Sortie Deck 不是又一个聊天框。按任务集结角色 Agent，用 LangGraph 编排出击航线， 关键门禁保留人在环，阶段之间用产物契约传递结果。

Brief→航线规划官→真人确认→ 角色 Agent→HITL→提测 / 交付

04 · 创新点

为什么不是「又一个 Agent 聊天」

控制面一等公民

任务、航线、HITL、产物都是一等对象，而不是埋在对话历史里。

可确认航线

规划官提案节点（含并行）；真人确认/手改后才编译图出击。

契约化产物

阶段写命名文件；下游读文件。并行路径作用域，避免互相覆盖。

图语义 HITL

interrupt() 暂停；放行 / 打回 / 改写 / 停止 / 重路由。
