# 多 Agent 协作模型

这一页描述 Sortie Deck 的协作模型：谁决定下一步、谁只是记录、什么时候必须停下来问人。

## 一句话分工

| 层 | 主体 | 职责 |
|----|------|------|
| 图（graph） | **Manager 的管控平面** | 承载整个需求的 plan、步骤与进度；是 manager 管控与可视化的载体，**不是** agent 路由的唯一权威。结构在编译期固定 |
| 大群 · 执行 | 角色 agent | 串行环节**自主 handoff** 给下一步 agent；执行过程中**随时自主发起小群** |
| Manager | 与 agent 分离的决策者 | 只在【并行汇合】【冲突/无法决策】【升级真人】时决策；事后标注步骤完成 |
| 小群 | 发起 agent + 参与者 + **全新的 manager 对象** | 自己的目标、计划与预算；记录不回流大群；**结论只回到发起它的那个 agent** |

## 路由规则（两条明确路径，不是二义性）

1. **串行**：agent 完成后自主 handoff → Manager **不介入**下一步，只标注该步完成。
2. **并行汇合**：多个 agent 同时完成，谁都不能替别人决策（会冲突）→ **Manager 决策**下一步执行哪个 agent。
3. **无法决策升级链**：agent 自行解决 → 升级 Manager → Manager 也解决不了 → 升级真人（钉钉/飞书），中断等待，回复后继续。

### 硬性不变量

- **handoff 白名单**：agent 可以自由决定交给谁，但目标必须同时满足「plan 已声明节点」+「源角色契约的 `handoff_targets` 白名单」。越界会被拒绝并回落编译期默认边。
- **HITL 不可被绕过**：`hitl_after` 的节点不允许 agent 自主跳过门槛；人必须在 agent 和下一节点之间。
- **预算封顶**：同一目标的 handoff 次数、任务级 handoff 总量、小群数量与 token 都设上限，超限即回落默认边而不是无限循环。
- **Manager 触发表写死**：只有【汇合】【冲突/无法决策】【升级】三类进入决策计算；其余路径零 LLM 开销。

## 小群（Sub-room）

- 由**执行 agent 随时自主发起**（agent 维度，不是 stage 节点预挂），初始提示词带发起者的疑问与上下文。
- 小群内有**新的 manager 对象**：独立实例，有自己的目标与计划。
- **深度上限 1**：小群内不可再开小群。
- 讨论记录**不回流大群**；只有结论作为 `mission` scope、`kind=episode`、`stage:<name>` 标签的记忆，注入**发起它的那一步**，避免污染并行分支。

## 打断与继续的一致性

- 每次启动任务都会冻结 **plan 摘要**（节点/角色/并行分组的稳定哈希）写入 `ini.meta.plan_digest`。
- 恢复时必须校验摘要一致：**plan 被改动过就拒绝恢复**，提示重新确认，而不是带病续跑。

## 升级梯子

```
agent 自己解决
   └─ 解决不了 → Manager 决策
         └─ 决策不了 → 真人（钉钉 / 飞书 / 工作台）
                         └─ 超时未回复 → fallback（默认 pause）
```

真人决策的可靠性护栏：`decision_id` 幂等（同一回复重复到达不会重复恢复）、决策人鉴权（非绑定人的回复只当聊天）、SLA 超时降级（默认 `pause`）、出站内容脱敏。

## 开关

**Agent 切换没有开关**：它本质是图的节点跳转，是唯一的路由机制，不保留旧逻辑。节点之间没有静态边——每个节点宣布下一跳，条件边消费它；冻结的 plan 只是这个路由器的默认分支。串行走 agent 提议（契约白名单校验），汇合走 Manager 决策，人工裁决也是同一种跳转。

其余能力默认**开启**。每一项都在依赖缺失时安全降级（无 LLM → 规则兜底；未配置 IM 通道 → 只进决策中心不推送），因此默认开启不会让任务卡死；不需要时把对应开关设为 `false`：

| 开关 | 默认 | 作用 |
|------|------|------|
| `TDT_PLAN_DIGEST_CHECK` | `true` | resume 前校验 plan 未被改动 |
| `TDT_SUBROOM_ENABLED` | `true` | 允许执行 agent 开小群 |
| `TDT_LOADOUT_AUTO` | `true` | 按需检索并加载能力（MCP / Skill） |
| `TDT_MCP_CALL_ENABLED` | `true` | 允许真正调用 MCP 工具（白名单 + 写确认） |
| `TDT_SKILL_RUN_ENABLED` | `true` | 允许执行 Skill 脚本（白名单 + 写确认） |
| `TDT_IM_ESCALATION` | `true` | 允许升级真人并推送 IM |

实现细节见 [协作模块](../modules/collaboration.md)。
